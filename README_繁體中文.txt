TODAY+ 第一版（手機 PWA 前端原型）

目前可使用：
- 新增任務：名稱、日期、時間、分類、優先順序、備註
- 任務完成／取消完成、刪除
- 今日、所有任務、本月任務、任務紀錄檢視
- 今日與本週完成率
- 手機瀏覽器本機儲存（localStorage）
- PWA 基本設定與離線快取

目前尚未接上：
- Google 帳號登入
- Supabase 雲端資料庫與跨裝置同步
- 背景推播／排程通知
- 真正的月曆格狀檢視與進階統計

重要：這一版資料只存在目前瀏覽器／裝置。清除網站資料或更換手機可能導致資料遺失，請先不要存放唯一的重要紀錄。

如何預覽：
1. 將此資料夾放到支援 HTTPS 的靜態網站主機（例如 GitHub Pages、Netlify 或 Vercel）。
2. 使用 Android Chrome 開啟部署後的 HTTPS 網址。
3. 從 Chrome 選單選「新增至主畫面」或「安裝應用程式」。
4. 若只在電腦直接雙擊 index.html，畫面可預覽，但 PWA 安裝與 Service Worker 不會完整運作。
